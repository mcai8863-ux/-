# 日进 0.1.5 开发与验收记录

本轮补齐核心记录流程，后续用户决定优先于历史 PRD。

## 已实现
- 新增事项、修改名称和目标、切换生活/工作/学习分类；同分类名称查重。
- 事项中切换经验库与改进记录；待整理记录可编辑并归入事项。
- 记录类型、发生日期、判断和独立日期的观察历史。
- 已尝试且判断保留后，依据观察结果确认沉淀，支持补充已有经验并建立关联。
- 经验全文编辑、关联记录与观察查看、有效状态筛选与恢复。
- 随手记正文草稿保留；新流程保存错误展示并保留编辑内容。
- 全部经验增加所属事项列，取消跨事项分组筛选。
- 新增 swift-format lint 入口。

## 验证
- 自动化验证重复沉淀复用来源经验、观察历史追加、缺乏证据拒绝沉淀、跨事项关联拒绝、待整理归类保留日期。
- 当前最低系统要求仍为 macOS 14.0。
