# 日进 PRD 审查意见

## 15. v0.3 需求审查与待决策项

审查对象：项目中的 PRD v0.2。结论：核心定位和主流程清楚，但部分状态、历史留存、数据恢复和交互仍不足以直接冻结开发。以下建议不是已获用户确认的范围变更。

### 15.1 已在本版修正

| 编号 | 问题 | 本版处理 |
| --- | --- | --- |
| C01 | 分组横排随着名称和数量增长挤占工具栏 | 采用用户确认的可搜索单选下拉；更新 P01、F11/F12、计数与异常规则 |
| C02 | F07 把类型与判断混成一个状态，P03 又漏掉未选择记录 | 与 7.1 对齐为两个字段；列表用派生显示状态，补“未标注”筛选 |
| C03 | 页面原型的旧横排分组与新文字要求冲突 | 旧图标为历史视觉参考；以 v0.3 新线框为当前交互依据 |
| C04 | “最近调整”未定义分组重命名等整理操作是否影响排序 | 明确内容调整与组织操作分开，单纯归类不让旧经验跳到最前 |

### 15.2 开发前优先决定

| 编号 | 优先级 | 不合理之处及具体后果 | 建议方案 | 当前状态 |
| --- | --- | --- | --- | --- |
| R01 | 高 | 记录、观察、判断、经验都有输入步骤；同一件事可能反复填写，偏离“想到就记” | 保留概念对象，但界面提供“补结果并沉淀”连续操作，带入已有文字，仅确认当前做法 | 待用户确认，不擅自删字段 |
| R02 | 高 | 经验更新覆盖当前正文，而原记录允许编辑；仅有关联记录不能准确还原当时为何改变 | 首版保留每次经验内容更新的只读快照及日期，不做复杂差异比较；编辑原记录仍不能修改旧快照 | 待用户确认是否加入版本历史 |
| R03 | 高 | 归档与不再适用混在一个操作里，恢复经验后是否重新有效不明确 | 归档表示收起来，有效性独立；恢复不自动变有效，需本人确认。事项恢复也不唤醒单独归档的子项 | 待确认；F17 与恢复验收不能据此直接实现 |
| R04 | 高 | 数据备份仍只有“开发前确定”，没有用户可执行的恢复路径 | 首版至少支持完整导出与恢复，包括事项、记录、观察、经验关联及扭蛋状态；恢复前预览并备份当前数据，不能静默覆盖 | 待确认最低交付范围，不选择存储服务 |
| R05 | 中 | “全部有效经验”“已归档”“不再适用”缺少统一入口定义，失效但未归档数据可能找不到 | 事项经验库增加可选状态筛选：当前有效、待复核、不再适用；归档仍由独立入口管理，默认只看当前有效 | 待确认，避免为了完整性马上增加工具栏控件 |
| R06 | 中 | 灵感分类切到生活，页面仍展示之前的学习签，会让人怀疑筛选失效 | 已有结果保留到抽取完成，但明确显示“下次范围：生活”；或按分类记忆最后一张。建议先采用前者 | 待确认，当前 13.6 为原建议 |
| R07 | 中 | 签库 ID 去重不能避免同主题反复出现；穷尽后历史池也可能连续重复相似建议 | 先试用当前随机规则，若重复感明显，再加入最近主题冷却；不要直接重写 600 条或引入复杂推荐 | 待试用验证 |
| R08 | 中 | 一条签永久只对应一个采纳记录，无法表达在不同事项重复尝试，也不支持误采纳撤回 | 默认防重复；在“查看想法”旁提供次级“另存一次尝试”，每次明确选择事项；撤回采纳只解除来源状态、不静默删除记录 | 待确认是否为首版需要 |
| R09 | 中 | 分组数量处理了，事项数量增长后侧栏仍可能很长；目前无事项搜索规则 | 增加侧栏事项搜索，按分类展示匹配项；暂不增加多层目录 | 待确认 |
| R10 | 中 | F01–F28 全部作为首版，混合核心闭环与展示优化；独立扭蛋窗口又增加窗口管理成本 | 先验收随手记到经验复用，再接预置灵感与采纳，最后调动画和窗口细节；不移除扭蛋目标 | 待确认交付顺序 |

### 15.3 文档与内容限制

- 600 条经过数量与文本检查，但没有用户逐条试用；是候选内容，不是有效性证明。标题字段尚不存在，继续以动作正文为准。
- P06/P07 为静态图，动画时长尚未试用。不要把图中所有尺寸直接当作实现约束。
- 快捷记录、归档、待复核、收藏、屏蔽等管理入口还没有全套可点击原型，开发前应走查最小闭环。
- 性能目标 1 万条、P95 500 ms 缺少指定设备和测量口径，属于候选目标，不应当作已有基线或预估承诺。
- 名称“日进 / Daily Better”为项目工作名，未完成同名与商标核查；个人原型阶段不因此阻塞。

### 15.4 建议的下一轮决策顺序

先讨论 R01 操作负担、R02 历史留存、R03 归档语义、R04 数据恢复。这四项会影响后续数据结构与核心体验。其余事项可在交互原型走查中逐步确定。未确认前不宣称 PRD 已达到可直接开发的冻结状态。
