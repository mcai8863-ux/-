# 日进 · Daily Better

日进（Daily Better）是一款 macOS 个人行为改进与经验管理应用，把成长当作一场持续的实验。围绕生活、工作和学习中的具体事项，随手记录想法与调整，观察实际效果，逐步沉淀可复用的经验。支持自定义事项与分组，以紧凑表格展示内容，清晰区分“待验证、验证中、已沉淀”，并提供搜索、筛选和 CSV 导出。没有灵感时，可通过“灵感扭蛋”获取一个可以立即尝试的小动作，自由选择采纳、不采纳或再想想。数据保存在本机，让每次微小改进成为下一次行动的积累。

## 核心用途

围绕生活、工作、学习中的事项，随手记录调整，观察结果，沉淀可复用经验。没有思路时通过灵感扭蛋获取一个小动作，由本人决定是否尝试。

## 项目状态

当前版本为 0.1.15，macOS 原生 MVP，持续试用与迭代中。中文工作名称：日进；英文工作名称：Daily Better。名称尚未进行商标或同名产品核查。

## 本地运行

项目使用 SwiftUI、SwiftData 和 Swift Package Manager，最低 macOS 14。

```bash
swift run DailyBetter
```

运行测试与 lint：

```bash
swift test
./scripts/lint.sh
```

构建本地应用（当前打包脚本面向 Apple Silicon）：

```bash
./scripts/build-app.sh
```

构建结果位于 `dist/日进-0.1.15.app`。需要 Xcode 工具链；本地开发不依赖在线 API、服务器或付费账号。构建采用本地 ad-hoc 签名。

## 已确定的方向

事项经验库采用密集表格与顶部可搜索的单选分组下拉筛选，无逐行展开，并支持经验导出。每条内容具有「待验证 / 验证中 / 已沉淀」成熟度，可在表格中直接修改并筛选；扭蛋采纳的建议进入对应事项后默认为「待验证」。每个事项可在「管理分组」中新增、重命名或删除自己的分组；删除分组时，其中的经验回到「未分组」。扭蛋和建议固定在同一页，点击「扭一次」或「再想想」直接刷新建议；建议提供“采纳 / 不采纳 / 再想想”三种操作。每轮不重复展示，播完一轮后由本人决定是否开始下一轮。学习签聚焦成年人的学习方法。SOP 不在当前范围内。

首版不提供归档。经验可标记为“不再适用”，但不会被移动到归档区。经验导出格式为 UTF-8 CSV，可直接使用 Excel、Numbers 等表格工具打开。

## 开发前

当前采用 SwiftUI、SwiftData 与本地 JSON，不依赖付费服务或 AI API。项目包含核心逻辑测试，lint 使用 Xcode 自带的 `swift-format`。

Git 仓库包含源码、测试、构建脚本、图标与产品文档；构建缓存、本地安装包、压缩归档和历史源码备份不纳入版本管理。
